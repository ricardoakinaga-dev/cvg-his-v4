# R5.1.1 — Notificações (SMS/WhatsApp + Email) — RESUMO

## ✅ Implementado

### Backend (`apps/his-api/src/modules/notifications/`)
- `schemas.ts` — Schemas Zod para validação
- `repo.ts` — Repositório com queries SQL para:
  - CRUD de templates
  - CRUD de notificações
  - CRUD de configurações
- `routes.ts` — Rotas da API:
  - `POST /notification-templates` — Criar template
  - `GET /notification-templates` — Listar templates
  - `GET /notification-templates/:id` — Detalhe do template
  - `PATCH /notification-templates/:id` — Atualizar template
  - `POST /notifications` — Criar notificação
  - `GET /notifications` — Listar notificações
  - `GET /notifications/:id` — Detalhe da notificação
  - `GET /notification-settings` — Obter configurações
  - `PUT /notification-settings` — Atualizar configurações
- `providers.ts` — Interfaces e implementações para:
  - Twilio SMS
  - Zenvia SMS
  - Twilio WhatsApp
  - 360Dialog WhatsApp
  - SendGrid Email
  - Mailgun Email
- `worker.ts` — Worker para processar notificações agendadas
- `index.ts` — Exportações do módulo

### Frontend (`apps/his-web/src/app/notifications/`)
- `page.tsx` — Página principal com:
  - Lista de notificações com filtros
  - Status badges coloridos
  - Ícones por canal
  - Paginação
- `settings/page.tsx` — Configurações com:
  - Toggle para cada canal (SMS, WhatsApp, Email)
  - Seleção de provedor
  - Campos de API key e números
  - Horário de silêncio
  - Configurações de retry
- `templates/page.tsx` — Gestão de templates com:
  - Lista de templates com filtros
  - Modal para criar/editar templates
  - Suporte a variáveis dinâmicas
  - Preview do conteúdo

### Contracts (`packages/contracts/src/notifications.ts`)
- Schemas completos para todas as entidades
- Contract tipado para API
