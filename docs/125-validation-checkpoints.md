# Validation Checkpoints

## Checkpoint obrigatorio por fase

Cada fase deve produzir:

- `phase-X-progress.md`
- `phase-X-validation.md`
- `phase-X-open-issues.md`

## Conteudo minimo do progress report

- escopo executado
- documentos e artefatos criados
- areas analisadas ou implementadas
- resumo do resultado da fase

## Conteudo minimo do validation report

- validacoes realizadas
- coerencia entre artefatos
- riscos remanescentes
- decisao de avancar ou bloquear

## Conteudo minimo do open issues report

- pendencias
- riscos
- dependencias
- decisoes a tomar
