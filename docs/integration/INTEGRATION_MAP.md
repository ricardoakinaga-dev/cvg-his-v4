## Notes

- Browser traffic is same-origin: `his-web` -> `/api/proxy/*` -> `his-api`.
- Proxy injects `Authorization` from `his_token` cookie and blocks client-controlled context headers.
- All API clients are centralized in `apps/his-web/src/lib/api/` directory.
- Feature-specific queries using React Query are in `apps/his-web/src/features/*/queries.ts`.
