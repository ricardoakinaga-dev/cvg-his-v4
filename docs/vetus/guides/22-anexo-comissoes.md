# VETUS — Relatório Anexo de Comissões
**Evidências principais:** `modulos/com-01-calculo.png`, `modulos/com-02-regras.png`, `rh-comissoes-01.png`, `rh-regras-comissao-01.png`

## 1. Síntese

O domínio de comissões existe com clareza no legado, mas a camada SPA mostra evidência fraca ou indisponível.

## 2. Evidências úteis

### 2.1 Cálculo de Comissões

`modulos/com-01-calculo.png` mostra uma tela legacy funcional com:

- título explícito `Cálculo de Comissões`;
- botão verde `Incluir`;
- filtro por profissional;
- filtro por data de cálculo;
- botão azul `Pesquisar`;
- grade com colunas de profissional, data do cálculo e abertura.

### 2.2 Regras de comissão

`modulos/com-02-regras.png` faz parte do mesmo domínio e, pelo agrupamento do acervo, representa a manutenção das regras que alimentam o cálculo.

## 3. Evidências problemáticas

No shell SPA:

- `rh-comissoes-01.png` é estado de indisponibilidade;
- `rh-regras-comissao-01.png` também é indisponibilidade.

Logo, o menu expõe a capacidade, mas a jornada beta não a entrega de ponta a ponta.

## 4. Conclusão

O módulo de comissões deve ser documentado como:

- **existente e funcional no legado**;
- **ainda não estabilizado na navegação SPA**.

Se a equipe precisar replicar ou migrar esse domínio, o legacy é a principal fonte de verdade.
