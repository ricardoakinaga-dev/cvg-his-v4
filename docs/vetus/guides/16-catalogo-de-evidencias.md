# VETUS — Catálogo de Evidências do Acervo
**Objetivo:** mapear explicitamente os arquivos de `screenshots/` e `modulos/` para domínio, leitura e status  
**Cobertura:** 152 arquivos visuais

## 1. Convenção de leitura

- **Funcional beta:** tela moderna carregada dentro do shell SPA
- **Funcional legacy:** tela clássica / JSF / PrimeFaces preservada em captura direta
- **Indisponível:** mensagem `Desculpe, página indisponível`
- **Erro HTTP:** `404` ou `500`
- **Estrutural:** captura usada para anatomia do shell ou do menu

- O acervo é grande, mas não homogêneo.

- O valor documental maior está nos grupos SPA maduros e nas telas legacy efetivamente funcionais.
- Os arquivos de indisponibilidade continuam importantes porque provam lacunas reais entre menu, rota e módulo final.
