## Ritual semanal sugerido

| Momento       | Objetivo                       | Participantes                        | Saida                           |
| ------------- | ------------------------------ | ------------------------------------ | ------------------------------- |
| Segunda-feira | Atualizar status e bloqueios   | `TL`, `BE`, `FE`, `PLAT`, `QA`, `PO` | Quadro da semana revisado       |
| Quarta-feira  | Revisao rapida de risco        | `TL`, `BE`, `FE`                     | Decisao sobre escalacao e corte |
| Sexta-feira   | Fechamento executivo da semana | `PO`, `TL`                           | Status, evidencias e pendencias |

## Regras de uso do quadro

- cada semana deve ter no maximo `2 objetivos principais`
- qualquer item `Bloqueado` por mais de `5 dias` deve subir para `TL` e `PO`
- nao iniciar frente nova de Onda 3 se Onda 1 residual estiver abrindo risco de release
- toda mudanca de status para `Concluido` deve apontar evidencia tecnica ou operacional

## Evidencias esperadas por linha

| Tipo de linha   | Evidencia minima                                            |
| --------------- | ----------------------------------------------------------- |
| Seguranca       | PR merged, teste automatizado ou checklist validado         |
| Observabilidade | dashboard, alerta ou endpoint verificado                    |
| SPA/DS          | tela entregue, teste visual ou adocao do componente         |
| API/OpenAPI     | spec publicada, endpoint documentado ou contrato revisado   |
| Integracao      | fluxo executado em ambiente interno com log e monitoramento |
| Governanca      | scorecard atualizado ou documento aprovado                  |
