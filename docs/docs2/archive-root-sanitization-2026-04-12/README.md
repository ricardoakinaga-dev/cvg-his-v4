# Archive Root Sanitization 2026-04-12

Este diretorio guarda documentos que estavam na raiz de `docs/`, mas nao fazem mais parte da trilha viva definida em `docs/README.md`.

Critérios de arquivamento aplicados nesta rodada:

- relatorios datados de auditoria ou instalacao que registram estados passados
- prompts operacionais usados como artefato de execucao, nao como referencia permanente
- comparativos e planos superados por `docs/vetus/` e pela trilha premium atual em `docs/Enterprise/`
- documentos cujo conteudo foi absorvido por guias canonicos mais recentes

Este arquivo e historico. Nao deve ser usado como instrução principal de deploy, migration, release ou roadmap atual.
