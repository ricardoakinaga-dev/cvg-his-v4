# Modulo Pacientes — Gate de Auditoria

## 1. Checklist obrigatorio

- [ ] create funciona com contrato completo;
- [ ] update funciona;
- [ ] list funciona com busca;
- [ ] detail funciona com tutor vinculado;
- [ ] tutor sempre presente e validado;
- [ ] integracao com Tutores funciona;
- [ ] alertas persistem e exibem;
- [ ] backend usa banco como fonte real;
- [ ] frontend sincronizado com backend;
- [ ] validacoes obrigatorias ativas;
- [ ] testes focados passando;
- [ ] typecheck passando;
- [ ] build passando.

- paciente sem tutor no fluxo principal;
- alertas nao persistindo;
- campos existentes apenas no frontend;
- validacoes ausentes.

- Apto para auditoria
- Apto com restricoes
- Nao apto
