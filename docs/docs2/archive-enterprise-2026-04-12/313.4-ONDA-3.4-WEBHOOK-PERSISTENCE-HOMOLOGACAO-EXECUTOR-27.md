## 5. Decisão de Fix — Gap de Migration 0009

Antes de executar os testes, é necessário verificar se a migration 0009 está sendo aplicada pelo global-setup ou se há um gap de drift. دو possibilities:

**Se a migration for aplicada pelo global-setup (via Drizzle):**

- Nada a fazer — setup está correto
- Os testes devem funcionar após iniciar o Docker

**Se a migration NÃO for aplicada:**

- A migration 0009 precisa ser adicionada ao setup de teste, OU
- O `global-setup.ts` precisa ser atualizado para aplicar raw migrations, OU
- O Drizzle schema precisa ser regenerado para incluir webhook tables na migration 0000

**Recomendação:** Antes de executar os testes WH, verificar manualmente se as tabelas `webhooks` e `webhook_deliveries` existem no banco de teste:

```sql
psql "postgres://postgres:postgres@localhost:5432/cvg_his_v2_test" \
  -c "\dt webhooks"
```

Se retornar `Did not find any relation named "webhooks"`, a migration 0009 precisa ser aplicada manualmente antes dos testes.
