# R5.1 — Integrações Externas (CVG HIS)

Data: 2026-03-18
Status: Planejamento

## Objetivo
Expandir o sistema CVG HIS com integrações externas para automatizar comunicação e criar parcerias comerciais.

---

## Sprint R5.1.1 — Notificações (SMS/WhatsApp + Email)

### Por que começar aqui?
- Automatiza comunicação com clientes
- Reduz no-shows em agendamentos
- Melhora experiência do cliente
- Base para futuras integrações

### Backend
- [ ] Criar módulo `notifications` em `apps/his-api/src/modules/`
- [ ] Criar tabela `notifications` (id, account_id, patient_id, type, channel, status, sent_at, content)
- [ ] Criar tabela `notification_templates` (id, account_id, type, channel, subject, body_html, body_text)
- [ ] Criar tabela `notification_schedules` (id, notification_id, scheduled_for, status)
- [ ] Criar endpoints:
  - `POST /notifications/send` - Enviar notificação
  - `GET /notifications` - Listar notificações
  - `GET /notifications/:id` - Detalhe da notificação
  - `PATCH /notifications/:id` - Atualizar status
  - `GET /notification-templates` - Listar templates
  - `POST /notification-templates` - Criar template
  - `PATCH /notification-templates/:id` - Atualizar template
- [ ] Criar worker para processar notificações agendadas
- [ ] Integrar com provedores:
  - **SMS**: Twilio (mais popular) ou Zenvia (brasileiro)
  - **WhatsApp**: Twilio WhatsApp API ou 360Dialog
  - **Email**: SendGrid ou Mailgun

### Frontend
- [ ] Criar página `/notifications` - Histórico de notificações
- [ ] Criar página `/notification-templates` - Gestão de templates
- [ ] Criar componente `NotificationConfig` em Settings
- [ ] Integrar botão "Enviar notificação" em:

  - Cash register close (receita)

- [ ] Resultado de exame disponível

## Riscos
- Dependência de provedores externos (Twilio, SendGrid)
- APIs de laboratórios podem não ser padronizadas
- Custo de SMS/WhatsApp pode ser alto

## Mitigações
- Usar provedores com boa documentação e suporte
- Começar com integração manual (upload) antes de API
- Implementar retry e fallback para notificações
